## 系統名稱由來

本系統命名為 **Aeterlux**，名稱源自兩個拉丁文字根的結合：

- **Aeter**：取自 Aeternitas（永恆），象徵記憶、情感與家族故事得以跨越時間延續。
- **Lux**：意為「光」，象徵生命價值、精神傳承與引導後人的希望。

因此，**Aeterlux 可詮釋為「永恆之光（Eternal Light）」**，代表即使生命終將逝去，其所留下的聲音、影像、故事與家族記憶，仍能透過數位技術被保存、傳承與延續。

本系統以**區塊鏈、永久儲存技術及生成式人工智慧**為核心，將個人生命歷程轉化為可長期保存的數位資產，並透過「記憶燈塔」的概念，為每一段生命留下一道永不熄滅的光，讓家族情感與人生故事得以跨世代傳承。

## 一、前言

人類自古以來，便透過墓碑、宗祠、族譜與遺物，試圖讓逝去的親人「被記住」。然而進入數位時代後，記憶的載體反而變得脆弱：照片存在 Google Drive 或 iCloud，一旦平台倒閉、帳號失效或停止繳費便可能消失；社群帳號在二十年後幾乎注定無人能登入；而我們對親人的記憶，最終往往只剩下靜止不動的相片與影片。

更深一層的問題是**所有權與隱私**。當記憶被託付給商業平台，使用者其實只是「租用」儲存空間，平台能讀取、能刪除、甚至能因商業決策而終止服務。家族最私密的影像與故事，從來不真正屬於家族自己。

傳統殯葬與紀念服務雖能提供實體塔位，卻無法承載數位時代的影音記憶，也無法讓後代「與先人對話」；市面上少數的數位紀念服務，則多半依賴單一公司的伺服器，一旦公司消失，記憶也隨之煙滅，本質上並未解決「記憶是租來的」這個根本痛點。

為解決上述問題，我們開發了 **Aeterlux 數位記憶燈塔**——一個結合 **區塊鏈所有權、Arweave 永久儲存、Lit Protocol 隱私加密與生成式 AI 數位分身** 的數位永生平台。它讓家族能真正**擁有**（而非租用）逝者的數位記憶，讓這份記憶**永久保存**（不依賴任何單一公司存活），並透過 AI 讓逝者「會說話、有表情、能對話」，將冰冷的相簿轉化為有溫度的跨世代傳承。

## 二、創意描述

**Aeterlux** 是一套專為「家族記憶傳承」打造的主權數位先祖系統，突破傳統紀念服務的限制，將記憶保存從 **「平台託管」** 推進至 **「家族主權」**，將先人緬懷從 **「靜態相簿」** 推進至 **「可互動的數位分身」**。

傳統的雲端相簿（如 Google Photos、iCloud）雖能儲存大量影音，但本質上是「租來的記憶」——平台倒了、欠費了、帳號失效了，記憶便消失；市面上的數位紀念網站多半建立在單一公司的伺服器上，無法保證長期存續，且使用者對隱私毫無掌控。這導致家族最珍貴的記憶，始終建立在「相信某家公司不會倒」的脆弱前提上。

Aeterlux 的核心創意，在於將三項去中心化技術與生成式 AI 結合，建構一個**即使本平台消失、記憶依然存在**的系統：

- **區塊鏈所有權（ERC-721 / ERC-6150）**：每一座數位記憶燈塔都是一枚獨一無二的 NFT，所有權寫在區塊鏈上，由家族的錢包持有，平台無法奪取或刪除；並以父子關係串接成「家族樹」，讓血脈與記憶在鏈上代代相連。
- **永久儲存（Arweave + Irys）**：照片、影片、聲音、文字與 AI 模型一次付費、永久保存於去中心化的 permaweb，不依賴任何單一伺服器。
- **隱私加密（Lit Protocol）**：私密內容加密後才上鏈，解密金鑰碎片化分散於去中心化節點網路，唯有持有對應 NFT 者，經鏈上驗證後才能解密——平台自己也看不到。
- **生成式 AI 數位分身**：透過影像模型重現逝者外貌、語音克隆重現其聲音、檢索式記憶（RAG）與大型語言模型重現其口吻與記憶，讓家族能與先人**即時視訊對話**。

其最大價值在於 **「主權」與「永恆」的結合**：家族不再把最重要的記憶託付給會倒閉的公司，而是真正擁有一份**寫在鏈上、存在 permaweb、由自己掌控金鑰**的數位遺產。即使第一代家屬全數離世，只要設定了繼承鏈，這座記憶燈塔仍能透過「死亡開關」自動傳承給下一代，實現真正的「數位宗祠永續」。

我們也針對目前市面上的相關服務進行了比較分析，下表為 Aeterlux、傳統實體塔位／殯葬服務、Web2 雲端紀念（如 Google Photos／紀念網站）與一般 AI 數位人服務的比較：

| 比較面向 | **Aeterlux 數位記憶燈塔** | 傳統實體塔位 / 殯葬 | Web2 雲端紀念（相簿 / 紀念網站） | 一般 AI 數位人服務 |

## 三、系統功能簡介

Aeterlux 的操作設計以「降低 Web3 門檻」為核心，讓不熟悉區塊鏈的家屬也能輕鬆使用。使用者只需依循以下步驟，即可完成建立與互動：

### 1. 一鍵登入（零門檻錢包）

家屬不需要懂助記詞或私鑰。透過 **Web3Auth（MPC 錢包）**，使用者只要用 **Google / LINE / Email 一鍵登入**，系統便在背後自動生成一個區塊鏈錢包，私鑰碎片化分散保管。使用者的體感與登入一般 App 完全相同，進階使用者則可隨時改連 MetaMask 等自持錢包，將資產轉為完全自主。

### 2. 建立記憶燈塔（鑄造 Mint）

家屬登入後，分三步建立逝者的數位記憶燈塔：

- **填寫基本資料**：姓名、性別、籍貫、生卒年月日、生平、墓誌銘。
- **上傳素材**：照片、影片、錄音、日記文章，以及與逝者的對話紀錄（LINE / WhatsApp / FB 匯出檔）。
- **簽署同意聲明並鑄造**：勾選肖像／聲音／文字使用同意聲明（上鏈存證），錢包簽名後鑄出一枚 **ERC-721 NFT**，即完成一座屬於家族、寫在鏈上的記憶燈塔。

### 3. 建構家族樹（純逝者譜）

系統採用「純逝者譜」設計：**塔位 NFT 只為已逝者鑄造，活人不鑄 NFT、不佔家族樹節點**。當家族中有成員過世，便為其鑄造新的塔位，並透過 ERC-6150 的父子關係接到已逝長輩之下，家譜自然往下延伸一代。活著的家屬則以「守護者 / 被授權成員」的身分（鏈上授權地址 + 角色），共同管理或瀏覽塔位——類似 GitHub 的協作者機制，一座燈塔可授權多人不同權限（瀏覽 / 上傳 / 管理）。

### 4. 設定公開與私密（隱私控管）

塔位守護者可逐項決定每個檔案的可見範圍：

- **公開（Public）**：任何人可見，如姓名、生卒年、大頭照、生平。
- **家族（Family）**：被授權的家族成員可見，如私人相簿、家庭影片。
- **私密（Private）**：僅持有人可見，如含活人隱私的對話紀錄。

切換時由守護者錢包簽名修改鏈上狀態，並同步通知 Lit Protocol 更新解密規則。

### 5. 與數位分身互動

家屬點選「啟動數位分身」後，系統以錢包簽名（SIWE，免 gas）證明持有 NFT，經 Lit Protocol 核對後解密取出 AI 模型，並由多個 AI 模組協作即時重現逝者：以**檢索式記憶（RAG）** 檢索生前日記與對話、以**大型語言模型（LLM）** 生成逝者口吻的回覆、以**語音克隆**重現其聲音、以**視訊化身技術**即時合成「會說話、有表情」的影像，再透過 WebRTC 低延遲串流到家屬畫面。家屬可以打字或說話，與先人用熟悉的臉孔、聲音與口吻**即時視訊對話**。

### 6. 線上公祭（房間制）

家屬可開設「公祭房間」並產生分享連結，親友（即使沒有帳號）也能進房，一同觀看紀念影像、聆聽 AI 數位分身講述，並即時留言互動。AI 數位分身會以「虛擬參與者」身分進房主講，讓遠距的家族成員得以共同緬懷。

## 四、系統特色

Aeterlux 與現有的紀念與儲存服務相比，具備以下獨特優勢：

- **真正的數據主權，而非行銷話術**
  所有權寫在區塊鏈、資料存於 Arweave、金鑰握於 Lit——三者皆去中心化。**即使本平台明天倒閉，只要 Arweave 還在、家屬持有 NFT 錢包，任何人都能用 NFT 指向的 TXID 把資料取回並重現逝者。** 這是賣點，也是技術上可驗證的承諾。

- **一次付費、永久保存**
  運用 Arweave 的「儲存捐贈基金」經濟模型，使用者一次付清即可永久保存，不必擔心月租到期或平台欠費導致記憶消失，徹底解決「記憶是租來的」痛點。

- **可互動的數位分身，而非靜態相簿**
  結合 RAG（記憶）、LLM（對話）、語音克隆（聲音）與視訊化身（外貌與表情），讓逝者「活過來」，家族能與先人即時對話，而非只能翻看冰冷的相片。

- **隱私加密，平台自己也看不到**
  私密內容經 Lit Protocol 加密後才上鏈，解密金鑰碎片化分散於去中心化節點，唯有持 NFT 者經鏈上驗證才能解密。即使少數節點被駭，也無法還原完整金鑰。

- **鏈上家族樹與跨世代傳承**
  以 ERC-6150 在鏈上記錄血緣關係，構成「純逝者譜」；並透過「預設繼承人」與「死亡開關」機制，即使第一代家屬全數離世，記憶燈塔仍能自動傳承給下一代，實現「數位宗祠永續」。

- **零 Web3 門檻**
  透過 Web3Auth MPC 錢包，家屬用 Google / LINE 登入即可，全程不需接觸助記詞、私鑰或加密貨幣，平台在背後處理所有區塊鏈與換匯的複雜性。

## 五、系統開發工具與技術

### 1. 前端開發技術

採用 **Next.js（React）+ TypeScript** 作為主要框架，提供高效能、模組化的使用者介面，支援家族樹視覺化、塔位頁、即時視訊對話與線上公祭房間。錢包與登入整合 **Web3Auth**（Google / LINE 登入）與 **wagmi / viem**，並以 **react-flow** 繪製家族樹、**Tailwind + shadcn/ui** 建構介面。

### 2. 後端開發技術

- 使用 **NestJS（TypeScript）** 建構主要後端服務，負責認證（SIWE 簽名驗證）、鏈上代理（viem / ethers）、任務佇列（BullMQ + Redis）與離鏈快取。後端定位為「加速與編排」角色，**並非權威來源**——所有權在鏈上、資料在 Arweave。
- AI 推理服務以 **FastAPI（Python）** 建構，負責影像、語音與對話模型的調度與串流。

### 3. 區塊鏈與去中心化基礎設施

- **智能合約（ERC-721 / ERC-6150）**：以 **Foundry** 開發 `DigitalTablet.sol`，部署於低 gas 的 EVM 區塊鏈（**Polygon / Base**，測試階段使用 Sepolia）。合約定義身分所有權、家族父子關係、守護者授權、資料指針、可見性與死亡開關。
- **永久儲存（Arweave + Irys）**：照片、影片、音檔、文字與 AI 模型加密後，透過 **Irys** 打包加速上傳至 **Arweave permaweb**，取得永久交易 ID（TXID）並寫入 NFT 的資料指針。
- **隱私加密（Lit Protocol）**：以去中心化節點網路管理解密金鑰，依「持有 NFT 才能解密」的存取控制條件，跨鏈核對 NFT 所有權後才釋出金鑰。

### 4. 資料庫技術

採用 **PostgreSQL** 作為離鏈快取與索引資料庫，儲存塔位的離鏈索引、守護者授權快取、公祭留言（短期保存）等加速用資料；搭配 **Redis** 處理任務佇列。此層僅為加速用途，可隨時由鏈上與 Arweave 重建，刪除不影響核心資產。

### 5. AI 技術

- **記憶建模（離線訓練）**：以影像標註模型（BLIP-2 / LLaVA）為照片自動打標，透過 **SDXL / Flux + LoRA 微調**學習逝者外貌；以**語音克隆（ElevenLabs PVC / IVC）** 從生前錄音複製音色，取得 voiceId；將日記與對話切片後以 embedding 建立 **RAG 向量記憶索引**（Qdrant / Chroma + multilingual-e5）。上述產物打包成 artifact，加密後上傳 Arweave。
- **即時互動（線上推理）**：互動時從 Arweave 取回並解密 artifact，由 **RAG 檢索記憶 + LLM 生成逝者口吻的回覆**，再以 **ElevenLabs（Flash 串流模型，<300ms）** 即時轉為逝者的聲音，以**視訊化身技術（Gaussian Splatting，<300ms）** 合成「對嘴 + 表情」的影像，最後以 **LiveKit（WebRTC）** 低延遲串流至家屬畫面，整體延遲控制在「視訊通話級」的順暢度。
- **科學化指標**：artifact 採開放格式（safetensors + 標準 RAG schema）並公開文件，確保即使平台消失，模型仍能被任何人解讀與重現。

## 六、系統使用對象

### 1. 一般家庭與家族

希望為過世的長輩建立一座永久、可互動、且真正屬於家族的數位記憶燈塔，讓家族故事與情感跨世代傳承。

不願將最私密的家族影像託付給可能倒閉、且能讀取自身資料的商業平台，重視「記憶由自己擁有、金鑰由自己掌控」的使用者。

### 3. 殯葬與生命禮儀業者

可將數位記憶燈塔作為傳統塔位與告別式的數位加值服務，提供家屬「實體 + 數位」並存的紀念方案，創造差異化服務。

### 4. 宗親會與家族組織

利用鏈上「純逝者譜」家族樹，建立可永久保存、可驗證、不依賴單一資料庫的數位族譜，凝聚跨地域的家族成員。

### 5. 文化與歷史保存機構

可將重要人物的生命歷程、口述歷史與影音資料，以去中心化方式永久保存並開放有限度的互動，作為數位文化資產。

## 七、系統使用環境

Aeterlux 為一款基於網頁的去中心化平台，使用者僅需具備可支援瀏覽器的電腦或行動裝置，並以 Google / LINE 一鍵登入即可使用，無需額外安裝應用程式、亦無需自行管理錢包或加密貨幣。

### 1. 最低使用需求

- **裝置**：桌上型電腦、筆記型電腦、平板或智慧型手機
- **作業系統**：Windows、macOS、iOS、Android 或其他主流系統
- **瀏覽器**：Chrome、Edge、Safari、Firefox（需支援 HTML5 與 WebRTC）
- **網路環境**：穩定的網際網路連線（即時視訊對話與公祭功能建議較高頻寬）

### 2. 最佳使用建議

- 進行 AI 數位分身的即時視訊對話或線上公祭時，建議使用桌上型或筆記型電腦，以獲得完整的互動體驗
- 建議搭配最新版瀏覽器，確保視訊串流、家族樹視覺化與資料呈現的最佳效果
- 建立塔位、上傳大型影音素材時，建議在穩定的 Wi-Fi 環境下進行

## 八、結語

**Aeterlux 數位記憶燈塔** 不僅是一個數位紀念平台，更是一套 **主權數位先祖系統**。它將記憶保存從過往的「平台託管」提升為「家族主權」，將先人緬懷從「靜態相簿」推進為「AI 驅動的可互動分身」，讓家族能在數位荒野中，為每一段生命建立一道永不熄滅的光。

藉由區塊鏈所有權、Arweave 永久儲存、Lit Protocol 隱私加密與生成式 AI，Aeterlux 解決了數位時代記憶最根本的三大難題：**記憶是租來的、帳號會消失、隱私無法掌控**。它讓家族真正擁有一份寫在鏈上、存於 permaweb、由自己掌控金鑰、且能與先人對話的數位遺產——即使本平台消失，這份記憶依然存在。

在生命終將逝去、而數位足跡卻日益龐大的時代，Aeterlux 代表的是一種新世代的傳承方式：不再讓記憶隨平台與帳號一同湮滅，而是透過去中心化技術與生成式 AI，將聲音、影像、故事與家族情感，化為一道跨越世代、永恆閃耀的光。
